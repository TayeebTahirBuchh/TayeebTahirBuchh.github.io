# Tayeeb Tahir Buchh — Portfolio

A responsive, static HTML/CSS/JavaScript portfolio designed for deployment on Vercel.

## Deploy to Vercel

1. Push `index.html` and `vercel.json` to the root of `TayeebTahirBuchh.github.io`.
2. In Vercel, choose **Add New → Project** and import `TayeebTahirBuchh/TayeebTahirBuchh.github.io`.
3. Choose **Other** as the framework preset.
4. Leave Build Command empty. Set Output Directory to `.` if Vercel asks for one.
5. Deploy. Future commits to the connected branch will trigger deployments.

No npm install or build step is required; this is a static site.

## Before publishing

- Check all contact and social links.
- Add a downloadable CV only after choosing the final CV file and path.
- Confirm the internship dates and project descriptions are accurate.
